# CISC 851 Group 5 "The Naturally Selected"

### Project Title: Symbolic Regression of Michaelis–Menten Enzyme Kinetics Using Tree-Based Genetic Programming

Enzyme kinetics data was obtained from Treloar (1974). The radioactive product formed during the reaction was measured in counts per minute at varying substrate concentrations (ppm). These measurements were then used to calculate the reaction’s initial velocity, expressed as counts/min/min.

To run the script, navigate to the project directory and in terminal run:
`python -m scripts.execute`
